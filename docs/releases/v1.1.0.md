# A moment for you v1.1.0

- Migrates the app to **.NET Framework 4.8**, using the runtime already included with Windows 10 version 1903 and later and Windows 11.
- Ships a small standalone Windows x64 EXE without bundling .NET 10, companion DLLs, or configuration files.
- Preserves the saved interval, opt-in Windows autostart, tray controls, multi-monitor overlays, homepage dismissal, and full interval restart after lock, screensaver, or sleep.
- Keeps per-monitor DPI support and the lower-right version, author credit, and project homepage link.
- Tests the released EXE from a folder containing only that file, and rejects release executables of 1 MiB or larger.

Download **A.moment.for.you.exe** directly, or extract the **win-x64.zip** and run **A moment for you.exe**. Older Windows 10 versions may require installing .NET Framework 4.8 first. A separate modern .NET runtime is not required.

Exit the old copy from its tray menu before replacing it. Saved settings remain compatible. If you move the executable to a different folder, turn **Autostart with Windows** off and on again from the new copy to update its location.

The release passes 23 automated checks, including runtime identity, older settings compatibility, scheduling, autostart, native monitor bounds, and footer placement at several display scales. The app remains unsigned.

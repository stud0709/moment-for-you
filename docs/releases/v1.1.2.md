# A moment for you v1.1.2

Fixes hidden break windows interfering with desktop interaction after closing and reopening a laptop lid, even when Windows stays unlocked.

- Dismiss active breaks and suspend reminders while the lid is closed or the session display is off. Returning starts a full new interval after every active away condition ends.
- Dismiss active breaks on monitor layout changes instead of recreating their windows during lid or docking transitions.
- Release all break windows when another window takes focus or after a long timer interruption, including missed sleep notifications.
- Keep manual pause settings, the immediate Done button, and the small standalone .NET Framework 4.8 executable.

Automated regression checks cover native power notifications, overlapping lid/display/sleep states, and cleanup of multiple hidden blocker windows. Hardware-specific lid and docking behavior still needs verification on the affected laptop.

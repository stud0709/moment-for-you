# A moment for you v1.0.0

The first release of a small Windows tray app for taking a moment away from screen work.

- Covers all connected monitors with a calm, opaque break screen.
- Reminds you to stand up, move around, and look at something at least 6 metres away for at least 20 seconds.
- Offers an immediate **Done** button, with no countdown. Take as long as you need; dismissing the break starts a fresh reminder interval.
- Includes a tray menu for setting the interval (1–240 minutes), taking a break now, pausing reminders, and exiting.
- Saves the interval and handles sleep, session locking, and monitor changes.

## Download and run

Download **A moment for you.exe** and open it, or download the **win-x64.zip** and extract it first. This is a self-contained Windows x64 build: no installer, administrator access, or separate .NET installation is required.

Close any older copy from its tray menu before starting this version. Closing the settings window keeps the app in the tray; use **Exit** to quit. The executable is unsigned, so Windows may show a reputation warning.

Use **Take a break now** to try the overlay. **Done**, **Esc**, or **Alt+F4** dismisses all break windows. This app is a reminder rather than a Windows security lock; Windows shortcuts and other privileged windows may appear above it.

The release workflow runs the packaged app's 13 automated checks before publishing. `SHA256SUMS.txt` contains SHA-256 hashes for the executable and ZIP.

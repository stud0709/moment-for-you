# A moment for you v1.0.5

- Adds **Autostart with Windows** in settings. When enabled, the app starts quietly in the tray when you sign in.
- Autostart is off by default, saves immediately, applies to the current Windows account, and can be removed by unchecking the option. No administrator access is needed.
- Refreshes the settings screenshot and expands the window to fit the new option.

Keep the portable executable in a stable folder. If you move it, turn autostart off and on again from the new copy. Exit any older running copy from its tray menu before launching this version.

The packaged app passes 22 automated checks. Autostart tests use isolated registry entries and do not enable actual Windows startup on the test PC.

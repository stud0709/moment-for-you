# A moment for you v1.0.3

- Clicking **Project homepage** also acts as **Done**, dismissing all break windows before opening the browser.
- Pauses the reminder countdown while Windows is locked, a screensaver is running, or the PC is asleep, then resumes the remaining time.
- Keeps the timer paused until all active away conditions end, and respects a manual pause when you return.
- Tests homepage action ordering, frozen countdowns, repeated screensaver checks, overlapping conditions, and interval changes while away.

Exit the old copy from its tray menu before starting this version. Your saved interval is preserved.
